# Triple Triad Solver

Web app, which uses a [minimax](https://en.wikipedia.org/wiki/Minimax) function to solve any given game of Triple Triad,
the Final Fantasy VIII minigame.

## Building

This is a Vite app and can be started using the following commands:

- `npm run dev` - run in dev mode with hot-reload
- `npm run build` - validate types and build to **./dist** directory
- `npm run preview` - serve contents of **./dist** directory locally
